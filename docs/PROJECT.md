# 项目范围与验收
## 毕业设计题目
基于大语言模型的电商智能客服 Agent 系统设计与实现。
## 架构
原生 Android 客服端与 Vue 买家/客服网页共用 Spring Boot 后端。数据库可用 MySQL 或单实例持久化 H2。模型调用仅从后端发起。
## Agent
最多4轮、每轮最多4次工具调用，最多同时2个生成任务；调用超时转人工。只开放 list_products、list_my_orders、get_my_order、search_knowledge。根据会话绑定买家身份，模型不能指定buyerId来绕过授权。订单工具结果不提供收货地址或买家ID。
所有回复均为草稿，人工审核后发送。发货和模拟退款不是模型工具，必须由客服主动确认。人工接管停止生成；生成过程中会话修订版本变化时，不保存过时草稿。
## 数据
用户、哈希密码、哈希会话令牌、商品库存、订单、售后、会话、消息、知识和操作审计均持久化。会话24小时失效。单店角色为BUYER和MERCHANT。
## 实验
准备订单/商品/政策/售后/越权/提示注入/模型故障案例，记录回答正确率、任务完成率、引用准确率、人工接管率、平均响应耗时。已实现的自动测试只证明流程与访问控制，不等于真实模型回复准确率。
## 本期取舍
商城支持直接购买和购物车批量结算；知识用字符匹配检索，没有向量模型；网页轮询消息，Android手动刷新；没有自动发送。先保证可验证的订单与客服闭环，再做扩展。
