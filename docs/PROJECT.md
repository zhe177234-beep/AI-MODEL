# 项目实施范围
## 定位
商家和人工客服使用的 Android 原生应用；买家从自建商城发起咨询。
## 目标架构
Android / Vue 商城 → Spring Boot → MySQL、知识库、模型 API。
## Agent 目标流程
接收问题 → 判断意图 → 核实身份与店铺权限 → 查询商品/订单/政策 → 生成草稿 → 人工审核或低风险自动回复 → 保存审计。
模型返回的工具参数必须经服务端验证；退款与地址修改需人工确认并提供幂等控制。
## 当前接口
GET /api/health：返回服务状态。
POST /api/demo/reply：JSON {"message":"我要退款"}；返回 mode、reply、requiresHuman。
这些接口仅用于初始联调，不是完整 Agent。
## 验收条件
两个不同买家订单不可越权查询；人工接管后自动回复停止；售后重复审批不重复执行；知识库回答可追溯；模型不可用时能转人工。
## 实验指标
回答正确率、任务完成率、越权拦截率、转人工率、平均响应耗时。
## 未完成
商城、数据库、登录与授权、消息系统、知识库、真实模型调用、工具执行、APK 和完整部署验证。
